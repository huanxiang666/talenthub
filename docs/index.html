FEATURES

从一份简历，到一座人才库

招聘全流程数字化：收集、解析、审核、跟进、统计、导出，一个系统闭环完成。

📄

批量简历导入

一次拖入 50 份 PDF / Word / 图片。文字版 PDF 直读、扫描版自动走内置离线 OCR（PP-OCRv4，中英混排）、Word 按文档顺序解析段落与表格。

PDF 文字层扫描 OCR.docx图片
🧠

22+ 字段结构化解析

姓名、电话、邮箱、微信、籍贯、政治面貌、学历、院校、专业、毕业年份、工作年限、当前/期望职位、薪资、技能、证书、多段工作经历……每份给解析置信度，低分标黄提醒人工核对。

🎯

精准人才管理

状态流水线可完全自定义、A/B/C/D 潜力评级、标签、跟进记录时间线、16 列全文搜索、多条件筛选、批量改状态/评级/打标签。

🔀

数据合并与去重

四种合并策略（跳过/补全/覆盖/总是新增），去重键 电话 > 邮箱 > 姓名，导入前逐行给出「新记录/疑似重复」预览分析；JSON 全量备份跨机器幂等合并。

📊

Excel 双向 + 仪表盘

带格式 xlsx 导出（双 sheet/冻结/筛选/着色）与别名表头导入；ECharts 仪表盘 4 卡片 5 图表，结论句由数据实时算出。

👁

简历在线预览

人才详情与投递审核中窗口内直接预览 PDF 原件与图片简历；列表行悬停即显示教育/经历/期望速览卡，无需点开。

AI PARSING

双引擎 AI 解析，非标准简历也能读懂

口语化、无字段标签、信息散乱的简历，规则解析置信度低时自动交给 AI 补全纠错。

本地小模型离线

内置 llama.cpp 推理引擎，纯 CPU 即可运行 Qwen2.5 / Qwen3 / Llama-3.2 / Gemma-3 共 7 档 GGUF 模型（0.5B ~ 4B）。设置页三源站一键下载（hf-mirror / ModelScope / HuggingFace），并根据你的内存与 GPU 自动推荐档位；有 NVIDIA 显卡可开 GPU 卸载加速。数据一个字节都不出机器。

Qwen2.5 0.5B/1.5B/3BQwen3-4BLlama-3.2Gemma-3GPU 加速可选

外部 API 引擎联网

接入任意 OpenAI 兼容接口：DeepSeek、OpenAI、通义千问、Kimi、本地 Ollama……填好地址与 Key 即用，解析质量更高、不占本机资源。API Key 仅保存在本机 config.json。

DeepSeekOpenAI通义千问KimiOllama
🛡

信任分层融合

语义字段 AI 优先；电话/邮箱等数字字段规则优先防幻觉；「至今」锚点保护当前公司判定；技能证书归一化合并去重。AI 失败自动回退规则结果，解析永不中断。

⚡

无模型也强

增强版规则解析独立可用（毫秒级）：姓名黑名单防误抓、学位表述归一、中文数字年限、固话兜底、邮箱 #/(at) 变体修复。非标准简历实测 15/15 关键字段全对。

🧪

一键自测

设置页「测试解析一份样本」按钮，当场验证你的模型或 API 配置是否工作，解析结果直接弹出对照。

APPLY PORTAL

独立投递门户，企业内部收简历

自动开启第二端口（默认 8301），把这个地址发给候选人或内部推荐人即可。

📮

候选人端

移动端友好的投递页：基本信息 + 简历附件 + 推荐人（内推场景）+ 自我介绍。提交即得 8 位查询码，凭「手机号 + 查询码」随时查进度、待审核期间可自助修改资料。

🧑‍💼

管理端审核

「投递审核」视图集中处理：窗口内预览简历 → 同意入选（自动解析建档转入人才库，推荐人写入标签）或 拒绝（附原因，投递人可查）。侧栏角标实时提示待审核数。

🚧

三重防滥用

图形验证码（一次性、防重放）+ 同 IP 每小时限 10 次 + 同手机号每日限 3 次；上传类型/大小白名单校验，路径逃逸防护。

SECURITY

数据在你手里，也受你保护

🔒

锁屏密码

自定义 6 位以上密码（PBKDF2 加盐哈希存储），启用后全部数据接口需解锁令牌访问；支持自动锁定（N 分钟无操作）。忘记密码时按页面指引删除 data/lock.json 即可清除，人才数据无损。

🏠

完全本地

SQLite（WAL）单文件数据库 + 原件目录都在程序旁边，整体拷贝即迁移备份；除「外部 API 引擎」为可选项外，全链路零联网依赖。

🧹

细节防护

Excel 导出防公式注入、上传文件类型/大小白名单、SQL 全参数化、API Key 掩码回显、操作日志可查可清。
